# Evaluation Rubric

## SVA Generation / Repair

- Syntax correctness under JasperGold
- Proof status on intended correct RTL
- Non-vacuity
- Repair success within 3 rounds
- Average rounds to success

## Failure Triage

- Issue type accuracy
- Recommended next-action accuracy
- Top-1 and top-3 root-cause accuracy
- Evidence support
- Hallucinated signal rate

## Coverage Closure

- Gap type accuracy
- Closure action accuracy
- Directed sequence usefulness
- Invalid/unreachable goal handling
